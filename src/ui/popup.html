X 回复榜

没能自动识别当前登录的 X 账号。请先打开或刷新一个 x.com 页面；仍识别不到就手动填写：

导出
  • 排名：统计范围内，别人在我帖子下回复我的次数。
  • 「我回 N」：同一范围内，我在他帖子下回复了几次。
  • 点头像去他的主页；点这一行其他地方，展开他回复我的每一条。
  • 次数小块的颜色和时间线标签一致，在设置页改。
  • 导出榜单：当前榜上的人；导出全量数据：本机存的每一条回复。

    数据读取

    • 「初始化」按统计范围往回读一遍，每次都从最新一条重新读，已有的不重复计数。
    • 限速执行：别人回我每小时约 4000 条。范围越大越久，一个月可能要读好几个小时。
    • 初始化之后靠「自动更新」只读新来的，每次随机隔 50–70 分钟。
    • 读取时要有一个 x.com 标签页开着，没有就顺延。
    • 本机只保留最近 45 天的数据，更早的自动清理。
    统计范围

    榜单、标签和初始化往回读多远都按它。改大后要再点一次「初始化」补数据。

    别人回我
    • 别人在我的帖子下直接回复我的。榜单排名和时间线标签用它。
    • 来源：X「通知 → 提及」的列表。
    • 不算：我去别人帖子下评论后对方回我的、引用、普通 @。

    我回别人
    • 我在别人帖子下的回复，按帖子是谁的记到谁头上。榜单里的「我回 N」用它。
    • 来源：我自己主页「回复」栏的列表。
    • 不算：我在自己帖子下回别人的。
    • 第一次读之前，插件会在后台开一个标签页到我主页的「回复」栏，看一眼 X 是怎么读这个列表的，几秒后自动关掉；X 改版后会自动再来一次。

    时间线上显示什么

    • 名次标签：榜上的人，名字旁显示名次和回复次数。
    • 关系：互 互关；粉 他关注我、我没关注他。其他情况不标。
    • M（只在通知列表）：这条回复是在我的帖子下。不在我帖子下的不标。
    • 关掉哪个，时间线上就不再显示哪个；数据照常读。

    榜单口径

    • 上榜只看两个条件：统计范围内至少回复几次、最多前几名。
    • 榜单和时间线标签共用。名次上限 10–500，次数 1–99，可直接输入数字。
    最多到第 名
    至少回复 次才上榜

    标签颜色

    • 按统计范围内的回复次数定颜色，从上往下先满足哪一档用哪个。
    • 最多 5 种颜色。都是实心底色，X 的深色、浅色主题下都看得清。

    风险说明

    读取用的是 X 网页版的内部接口，不是官方 API，属于服务条款的灰色地带，可能导致账号被限流。本插件只读、低频，不做任何点赞、关注、发帖操作；关掉「自动更新」后不再向 X 发任何请求。数据只存在本机，不上传。风险自担。

    清空数据

    清掉该账号在本机的两份回复数据和读取进度，榜单和时间线标签都会消失，不可恢复。账号绑定和设置保留。
