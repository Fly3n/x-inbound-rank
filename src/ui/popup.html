X 回复榜

没能自动识别当前登录的 X 账号。请先打开或刷新一个 x.com 页面；仍识别不到就手动填写：

    数据读取

    别人回我

    别人在我帖子下的回复。榜单排名和时间线标签用它。

    我回别人

    我在别人帖子下的回复。榜单里的「我回 N」用它。

    榜单口径

    最多到第 名
    至少回复 次才上榜

    榜单和时间线标签共用，可直接输入数字。

    标签颜色

    按回复次数定颜色，从上往下先满足哪一档用哪个。

    帮助与原理

    两份数据从哪来

    别人回我：读 X「通知 → 提及」的列表，只留别人在我的帖子下直接回复我的。我去别人帖子下评论后对方回我的、引用、普通 @ 都不算。

    我回别人：读我自己主页「回复」栏的列表，只留我在别人帖子下的回复，按帖子是谁的记到谁头上；在我自己帖子下回别人的不算。第一次需要在 X 上点开一次自己主页的「回复」栏，X 改版后可能要再点一次，到时这里会提示。

    读取方式

    启动 / 初始化：按榜单页选的统计窗口（7 天或半个月）往回读，每次都从最新一条重新读，已有的不会重复计数。限速执行，每小时大约读 4000 多条，半个月耗时大约翻倍。

    自动更新：每次随机隔 50–70 分钟，只读上次之后新来的；单次最多约 800 条，超过的部分放弃。遇到 X 限流会自动暂停，过后续上。

    所有读取都要有一个 x.com 标签页开着，没有就顺延到下次打开 X。

    榜单和标签

    统计窗口内按回复次数排名。上榜条件只有两个：至少回复几次、最多前几名。时间线标签显示「名次 + 回复次数」，颜色按回复次数分档；标签只读本机数据，不发请求。

    占用

    本机只存每条回复的作者、时间、所在对话和 100 字以内的摘要，只保留最近 30 天，更早的每天自动清理。

    风险

    读取用的是 X 网页版的内部接口，不是官方 API，属于服务条款的灰色地带，可能导致账号被限流。本插件只读、低频，不做任何点赞、关注、发帖操作；关掉「自动更新」后不再向 X 发任何请求。数据只存在本机，不上传。风险自担。

    清空数据

    清掉该账号在本机的两份回复数据和读取进度，榜单和时间线标签都会消失，不可恢复。账号绑定和设置保留。
