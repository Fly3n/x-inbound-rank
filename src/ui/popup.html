导出
  • 排名：所选范围内，他在我的帖子下回复我几次，不分第几层。
  • 「我回 N」：同一范围内，我直接评论他的帖子几次（只算第一层）。
  • 范围可以比补历史读的长：数据是攒出来的，本机最多存 3 个月。
  • 点头像去他的主页。点这一行其他地方，看双方回复的时间；悬停时间可看回复摘要，点击打开原文。
  • 次数小块的颜色和时间线标签一致，在设置页改。
  • 导出榜单：当前榜上的人；导出全量数据：本机保存的全部统计相关记录，仅用于判定归属的内部记录不导出。

    数据读取

    开启自动更新后，别人回我无需先补历史即可按天慢慢积累，每天上午（08:00–11:30）和晚间（18:00–22:30）在当前 X 页面可见且最近 5 分钟内有真实浏览交互时各随机执行一次，发现与上次位置重叠即停（单轮安全上限 60 页）。我回别人默认通过浏览器发帖旁听实时记录，如需手机端回复兜底可在下方开启每 2 天低频自动同步。「立即更新」同样不要求先补历史，有 10 分钟冷却，成功后下一次自动更新放到下一时段。

    补历史范围

    点「补历史」时往回读多远。榜单看多久在榜单页单独选。补读只在 X 页面可见时继续，切走就暂停；不补历史也能直接开启自动更新慢慢攒。

    别人回我

    统计在我自己的帖子下回复我的次数，各层都算，决定榜单排名。

    我回别人

    统计我直接评论对方根帖的次数，在榜单显示「我回 N」。默认仅通过浏览器发帖旁听实时记录（零主动请求）；也可按需点「补历史」或开启低频同步兜底。

    打开我的回复页
    本机存储（两份数据合计）

    时间线和发帖时显示什么

    选择名字旁显示的标签，以及排期弹窗里的快捷档期。互是互关，粉是对方关注你，M 表示通知里的回复发生在你的帖子下。排期开关不受自动更新开关影响。

    榜单口径

    先按回复次数筛选，再取前几名。榜单和时间线标签共用这两个设置。

    最多到第 名
    至少回复 次才上榜

    标签颜色

    颜色按回复次数分档，从最高门槛向下匹配。

    效果预览：

    数据怎么读取
    • 别人回我：读取 X 的「通知 → 提及」。日常打开通知页后可用新版读取方式。
    • 我回别人：默认通过浏览器发帖实时旁听记录（零主动请求）；开启低频自动同步或点「补历史」时才读取回复栏，首次缺少读取参数时按提示打开回复页一次即可自动继续。
    • 不补历史也能直接开启自动更新慢慢攒；补读只在页面前台显示时继续，切走就暂停。所有主动读取只在本地时间 08:00–24:00 进行。
    • 自动更新每天上午、晚间各随机一次，已有记录按帖子 ID 去重。X 页面必须在前台显示且近期有浏览交互；白天亮屏离座、后台标签页和最小化窗口不会发请求。
    • 关闭自动更新不会影响「补历史」或「立即更新」；手动读取同样只在页面前台显示时发出请求。
    统计口径与读取频率
    • 别人回我：在我自己的帖子下直接回复我的都算，各层都计入。
    • 我回别人：只算我直接评论对方根帖的第一层。
    • 别人回我每天上午、晚间各随机检查一次，发现与上次接续点重叠即停（单轮安全上限 60 页）；我回别人默认零主动请求实时旁听，启用低频同步时每 2 天抽一次检查。
    • 后台页间停顿与补历史批间隔均按非均匀间隔模拟真人操作；手动更新有十分钟冷却。
    风险说明

    读取用的是 X 网页版的内部接口，不是官方 API，属于服务条款的灰色地带，可能导致账号被限流。插件按人的作息设计：只在本地时间 08:00–24:00、X 页面前台可见时请求；每天低频读取，夜间和后台标签页零自动请求。全程只读，不点赞、不关注、不发帖；数据只存在本机。风险仍无法保证为零。

    清空数据

    清掉该账号在本机的两份回复数据和读取进度，榜单和时间线标签都会消失，不可恢复。账号绑定和设置保留。

    账号

    按 X 的数字用户 ID 识别账号，改 @用户名 不会改变数据归属。关闭会暂停此账号的功能和更新，保留本机数据。
