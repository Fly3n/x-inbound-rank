导出
  • 排名：所选范围内，他在我的帖子下回复我几次，不分第几层。
  • 「我回 N」：同一范围内，我直接评论他的帖子几次（只算第一层）。
  • 范围可以比补历史读的长：数据是攒出来的，本机最多存 3 个月。
  • 点头像去他的主页。点这一行其他地方，看双方回复的时间；悬停时间可看回复摘要，点击打开原文。
  • 次数小块的颜色和时间线标签一致，在设置页改。
  • 导出榜单：当前榜上的人；导出全量数据：本机保存的全部统计相关记录，仅用于判定归属的内部记录不导出。

    补历史
    补读范围

    按需手动拉取过去 7 天或半个月的历史补齐；不补也能靠日常「旁听收集」慢慢攒。仅在 X 页面前台可见时继续，切走自动暂停。

    别人回我

    统计在我自己的帖子下回复我的次数，各层都算，决定榜单排名。

    我回别人

    统计我直接评论对方根帖的次数，在榜单显示「我回 N」。默认通过浏览器发帖旁听实时记录（零主动请求），也可按需手动补历史。

    打开我的回复页

    数据同步

    开启后，你在电脑浏览 X「通知 / 提及」页时自动旁听并去重记录回复（零主动请求，后台不再定时抓接口）。右侧「立即更新」为按需手动拉取（10 分钟冷却），仅在你主动点击时发请求。

    开启后，你在电脑发回复或浏览本人主页「回复」栏时自动旁听并去重记录（零主动请求，后台不再定时抓接口）。右侧「立即更新」为按需手动拉取（10 分钟冷却），可用于补齐手机端回复。

    页面显示

    选择 X 页面名字旁显示的标签，以及排期弹窗里的快捷档期。互是互关，粉是对方关注你，M 表示通知里的回复发生在你的帖子下。排期开关不受自动更新开关影响。

    榜单口径与标签颜色

    先按回复次数筛选，再取前几名；颜色按回复次数从最高门槛向下匹配。榜单和时间线标签共用这些设置。

    本机存储与清空数据

    清空会删掉该账号在本机的两份回复数据和读取进度，榜单和时间线标签都会消失，不可恢复。账号绑定和设置保留。

    账号管理

    按 X 的数字用户 ID 识别账号，改 @用户名 不会改变数据归属。关闭会暂停此账号的功能和更新，保留本机数据。

    口径与风险说明
    • 别人回我：根帖是我的帖子，直接回复我的每一条都算（不分层），决定榜单排名。默认在浏览 X「通知 / 提及」页时零请求旁听收集。
    • 我回别人：只算我直接评论对方根帖的第一层。默认在电脑浏览器发回复及浏览本人「回复」栏时零请求旁听收集。
    • 零后台定时抓取：后台不再自动定时请求 X 接口；仅在你手动点「立即更新」或「补历史」时在 08:00–24:00 前台按需读取，命中账号异常或连续限流立即硬熔断。
    • 隐私与风险：全程只读 GET，不点赞、不关注、不发帖，数据仅存本机（滚动保留最近 90 天）。手动拉取使用网页内部接口仍无法保证风险为零。
