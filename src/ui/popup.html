X 友

导出
  • 排名：所选范围内，他在我的帖子下回复我几次，不分第几层。
  • 「我回 N」：同一范围内，我直接评论他的帖子几次（只算第一层）。
  • 范围可以比初始化读的长：数据是攒出来的，本机最多存 3 个月。
  • 点头像去他的主页。点这一行其他地方，看双方回复的时间，点时间打开原文。
  • 次数小块的颜色和时间线标签一致，在设置页改。
  • 导出榜单：当前榜上的人；导出全量数据：本机存的每一条回复。

    数据读取

    初始化补齐所选时段，自动更新只读取之后的新回复。榜单范围在榜单页单独设置。

    初始化范围

    点「初始化」时往回读多远。榜单看多久在榜单页单独选。

    别人回我

    统计在我帖子下直接回复我的次数，决定榜单排名。

    数据状态
    我回别人

    统计我直接评论对方根帖的次数，在榜单显示「我回」。

    数据状态

    打开我的回复页
    本机存储（两份数据合计）

    时间线上显示什么

    选择名字旁显示的标签。互是互关，粉是对方关注你，M 表示通知里的回复发生在你的帖子下。

    榜单口径

    先按回复次数筛选，再取前几名。榜单和时间线标签共用这两个设置。

    最多到第 名
    至少回复 次才上榜

    标签颜色

    颜色按回复次数分档，从最高门槛向下匹配。

    效果预览：

    数据怎么读取
    • 别人回我：读取 X 的「通知 → 提及」。日常打开通知页后可用新版读取方式。
    • 我回别人：读取我的主页「回复」栏。首次缺少读取参数时，按提示打开回复页，随后自动继续。
    • 初始化补读历史记录。自动更新从上次进度接着读，已有记录按帖子 ID 去重。需要有已登录的 X 页面打开。
    统计口径与读取频率
    • 别人回我：在我自己的帖子下直接回复我的都算，各层都计入。
    • 我回别人：只算我直接评论对方根帖的第一层。
    • 自动更新约每小时一次。别人回我分批读取，我回别人每批最多 5 页，未读完时休息 3–5 分钟再继续。
    风险说明

    读取用的是 X 网页版的内部接口，不是官方 API，属于服务条款的灰色地带，可能导致账号被限流。本插件只读、低频，不做任何点赞、关注、发帖操作；关掉「自动更新」后不再向 X 发任何请求。数据只存在本机，不上传。风险自担。

    本地诊断日志

    保留最近 7 天。显示最近 10 条，导出包含帖子编号、请求条件和处理原因，分享前请先检查。

    按时间回查「别人回我」

    从最新提及往前查，单次最多 20 页。自定义时间按浏览器本地时区。
